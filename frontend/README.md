# Career Platform MVP — Frontend

Web frontend for **PathPilot**, the international career mobility MVP. Built with
[TanStack Start](https://tanstack.com/start) (React 19, SSR + file-based
routing). Users create a **career profile** (education, experience, skills,
languages, location preferences, interests), get a ranked list of
**recommendations** where every match is explained point by point, explore the
**opportunity catalog**, and manage a **shortlist** of saved roles.

It talks to the FastAPI backend (`../backend`) exclusively through a
**generated, fully typed API client** — no hand-written fetch/axios calls.

## What it does (user-facing pages)

| Route                           | Page                                                                                             |
| ------------------------------- | ------------------------------------------------------------------------------------------------ |
| `/`                             | Home — active profile summary, entry points to create/edit a profile                             |
| `/profiles`                     | Profile list + switcher (the header also switches the active profile)                            |
| `/profiles/new`                 | Create a career profile (TanStack Form, zod-validated)                                           |
| `/profiles/$profileId/edit`     | Edit an existing profile                                                                         |
| `/recommendations`              | Ranked matches for the active profile, with per-dimension score breakdowns and eligibility flags |
| `/opportunities`                | Browse the seeded opportunity catalog (filterable)                                               |
| `/opportunities/$opportunityId` | Opportunity detail + the explained match vs. the active profile                                  |
| `/shortlist`                    | Saved opportunities for the active profile                                                       |
| `/about`                        | About the project                                                                                |

Includes dark/light/auto theming (persisted to `localStorage`, no flash on load).

## Tech stack

| Concern       | Choice                                                                                    |
| ------------- | ----------------------------------------------------------------------------------------- |
| Framework     | TanStack Start 1.x — SSR, file-based routing (`src/routes`)                               |
| UI runtime    | React 19, TypeScript                                                                      |
| Data fetching | TanStack Query 5 (hooks generated by Kubb)                                                |
| Forms         | TanStack Form 1 (validation via generated zod v4 schemas)                                 |
| API client    | Kubb-generated axios clients + TanStack Query hooks (`src/gen/`)                          |
| Styling       | Tailwind CSS v4, shadcn/ui components (`src/components/ui`), Radix UI, lucide-react icons |
| Build tooling | Vite 8, ESLint (@tanstack/eslint-config), Prettier                                        |

## Workflow: how a page talks to the backend

```
┌─ frontend (Vite dev server, port 3000) ─────────────────────────┐
│                                                                 │
│  src/routes/*.tsx — pages (file-based routing)                  │
│       │                                                         │
│       ▼                                                         │
│  src/hooks/ + src/lib/ — career form logic ·                    │
│  active profile · error mapping                                 │
│       │    ▲                                                    │
│       │    ┆ form validation — src/gen/zod/                     │
│       │    ┆ (zod schemas, Kubb-generated)                      │
│       ▼                                                         │
│  src/gen/queries/ — TanStack Query hooks (Kubb)                 │
│       │                                                         │
│       ▼                                                         │
│  src/gen/clients/ — axios functions (Kubb)                      │
│                                                                 │
└────────────────┬────────────────────────────────────────────────┘
                 │  HTTP JSON — ApiResponse envelope     ▲
                 │  {success, data, message, meta}      ┆ openapi.json
                 ▼                                      ┆ → kubb generate
                                                        ┆   (npm run gen:api)
   FastAPI backend :8000 — /api/v1/*                    ┆ → regenerates src/gen/
```

Key points:

- **`src/gen/` is generated code — never edit it by hand.** Regenerate with
  `npm run gen:api` (backend must be running). It is excluded from
  prettier/eslint.
- Responses use the backend's `ApiResponse` envelope and are consumed as-is.
  Errors throw a `ResponseError` whose `.data` carries the `ErrorResponse`
  envelope; `src/lib/api-errors.ts` maps its `details[].field` entries onto
  TanStack Form field errors (e.g. duplicate email → the email input).
- The API base URL defaults to `http://localhost:8000` (origin only — the spec
  paths already include `/api/v1`); override with `API_BASE_URL=... npm run gen:api`.

## Run instructions (in order)

Prerequisites: Node.js 20+ and npm. The **backend must be running** for the app
to be useful (see `../backend/README.md`).

```bash
cd frontend

# 1. Install dependencies
npm install

# 2. Start the dev server (Vite, port 3000)
npm run dev          # → http://localhost:3000
```

That's it for day-to-day development. The generated client (`src/gen/`) is
committed, so regeneration is only needed when the backend API changes.

### Regenerating the typed API client

```bash
# terminal 1 — backend running on :8000
cd ../backend && uv run uvicorn app.main:app --reload --port 8000

# terminal 2 — regenerate src/gen from the live OpenAPI document
cd ../frontend
npm run gen:api
```

### Production build

```bash
npm run build        # vite build
npm run preview      # serve the production build locally
```

### Linting & formatting

```bash
npm run lint         # eslint
npm run format       # prettier --write . && eslint --fix
npm run check        # prettier --check .
```

## Project layout

```
src/
├── routes/          # File-based routes (one file per page — see table above)
├── components/      # Header, Footer, career-profile-form, match, shortlist-button, ui/ (shadcn)
├── hooks/           # career.form.ts, form-contexts.ts
├── lib/             # active-profile context, api-errors mapping, career-form helpers, utils
├── integrations/    # TanStack Query provider + devtools
├── gen/             # ⚙️ Kubb-generated API client (types, zod, clients, queries) — do not edit
├── router.tsx       # Router instance (queryClient context for SSR)
└── styles.css       # Tailwind CSS v4 entry + theme tokens
kubb.config.ts       # API client generation config (input: live OpenAPI URL)
vite.config.ts       # Vite + TanStack Start + Tailwind plugins
```
